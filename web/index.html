推荐 GitHub Repo 目录架构

Data-View Decoupled

将后训练标准阶段（Backbone）、痛点分类（Problems）与各模型独立配方及专属拓扑（Recipes）拆分为独立 JSON，社区贡献者只需提交单个模型的 JSON 文件即可通过 GitHub Action 自动合入网页与 README。 

awesome-100b-post-training/
├── data/
│   ├── backbone.json        # 固定的 6 大后训练阶段定义
│   ├── problems.json        # 6 大核心工程/算法痛点字典
│   └── recipes/             # 每个模型独立一个 JSON (含专属拓扑节点)
│       ├── rufus-air-106b.json
│       ├── intellect-3.1-106b.json
│       ├── nemotron-3.5-super.json
│       ├── glm-5-744b.json
│       ├── deepseek-v4.json
│       ├── mimo-v2.6.json
│       └── minimax-m2.5.json
├── scripts/
│   ├── build_site_data.py   # 校验 JSON 并打包生成前端数据
│   └── generate_readme.py   # 自动生成 README 静态 Markdown 对比表
├── docs/
│   └── index.html           # 当前交互式看板 (GitHub Pages 直接托管)
└── README.md
